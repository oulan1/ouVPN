## 📖 О проекте

**ouVPN** — проект, предоставляющий открытый доступ к надежным и быстрым VPN-серверам со всего мира. Серверы автоматически синхронизируются через GitHub Actions, а также могут отбираться и проверяться вручную через удобную локальную панель управления.

Все новости, анонсы и свежие события публикуются в нашем официальном Telegram-канале **[@oulanGift](https://t.me/oulanGift)**.

## ✨ Ключевые возможности

- ⚡ **Два режима обновления на выбор:**
  - 🤖 **GitHub Actions (автоматический)**: 
    1. *Быстрое обновление всех серверов* (каждый час в :10 минут)
    2. *Обновление только рабочих серверов* (с проверкой HTTP GET 204 через Xray)
  - 🖥️ **ouVPN Control Panel (ручной с ПК)**: графическая панель для проверки реального пинга из вашей сети, выбора серверов галочками или номерами и быстрой публикации на GitHub.
- 🎯 **Удобная нумерация и отметки:**
  - Каждый сервер имеет свой ID (например, `NL 🇳🇱 ouVPN V2 | #2`).
  - Быстрые серверы можно помечать знаком `⚡` (двойным кликом в панели).
- 🧭 **Идеальная сортировка серверов:**
  1. 🇪🇺 Европейские страны (с наименьшим пингом вверху)
  2. 🌐 Международные страны (US, CA и др.)
  3. 🇷🇺 Российские серверы
  4. 🛡️ Серверы обхода (`🇪🇺 Обход №... | #ID`) в самом низу
- 💸 **Абсолютно бесплатно** — никаких ограничений и платных подписок.
- ⚙️ **Гибкая шапка подписки** — файл `heading.txt` позволяет настроить формат шапки и анонсов под свои задачи.

## 🖥️ Как запустить ouVPN Control Panel на ПК

В папке репозитория на вашем компьютере находится удобный батник:
1. Запустите файл **`ouVPN_Panel.bat`** (или **`Запустить_Панель.bat`**).
2. Нажмите **«📥 Извлечь текущие сервера»** — панель загрузит актуальный список.
3. Нажмите **«⚡ Проверить пинг (HTTP 204)»** — скрипт проверит доступность серверов через реальный запрос к Google.
4. Отметьте нужные серверы галочками, либо введите их номера через запятую в поле (например: `1, 2, 5, 10-20`), либо нажмите **«✅ Только рабочие»**.
5. Двойной клик по серверу выделяет его **золотым цветом** и добавляет значок **`⚡`** (скоростной).
6. Нажмите **«🚀 Опубликовать на GitHub (Push)»** — файл `ouvpn.txt` будет сформирован и отправлен в репозиторий!

## 📂 Структура репозитория

* 🌍 [`ouvpn.txt`](./ouvpn.txt) — актуальный файл подписки с серверами.
* 📝 [`heading.txt`](./heading.txt) — шаблон шапки подписки с поддержкой динамических переменных (`{date}`, `{time}`, `{count}`, `{interval}`).
* 🖥️ [`panel.py`](./panel.py) / [`ouVPN_Panel.bat`](./ouVPN_Panel.bat) — графическая панель управления серверами.
* 🧠 [`core_engine.py`](./core_engine.py) — общее ядро парсинга, тестирования пинга через Xray и сортировки.
* 🐍 [`update_configs.py`](./update_configs.py) — скрипт быстрого обновления всех серверов.
* 🛡️ [`update_verified.py`](./update_verified.py) — скрипт обновления проверенных серверов с фильтрацией по пингу.
* ⚙️ `.github/workflows/` — сценарии GitHub Actions:
  - `update_all.yml` — категория 1: быстрое обновление всех серверов.
  - `update_verified.yml` — категория 2: проверка пинга и отбор живых серверов.
* 🌐 [`index.html`](./index.html) — стартовая страница подключения для пользователей ([сайт](https://oulan1.github.io/ouVPN/)).

## 🚀 Как подключиться

Для использования наших серверов рекомендуется приложение **Happ**:

### Способ 1: Автоматическое добавление (в 1 клик)
1. Установите [Happ](https://www.happ.su/main/ru).
2. Перейдите на сайт **[oulan1.github.io/ouVPN](https://oulan1.github.io/ouVPN/)** и нажмите **«Добавить подписку»** (или откройте ссылку: `happ://add/https://raw.githubusercontent.com/oulan1/ouVPN/refs/heads/main/ouvpn.txt`).
3. Подписка загрузится сама и будет обновляться автоматически!

### Способ 2: Вручную через ссылку на подписку
1. Скопируйте ссылку на подписку:
   ```text
   https://raw.githubusercontent.com/oulan1/ouVPN/refs/heads/main/ouvpn.txt
   ```
2. В приложении **Happ** нажмите «+» / «Добавить подписку» и вставьте скопированную ссылку.
3. Выберите нужный сервер (например `NL 🇳🇱 ouVPN V2 | #2` или `🇪🇺 Обход №1 | #4`) и нажмите подключиться.

## 🛠️ Настройка шапки подписки (`heading.txt`)

Вы можете в любой момент изменить текст шапки прямо в файле `heading.txt`. Скрипт поддерживает следующие переменные:
- `{count}` — текущее количество серверов
- `{interval}` — интервал обновления (1 час)
- `{date}` — дата по МСК (ГГГГ-ММ-ДД)
- `{time}` или `{hh:mm}` — время по МСК (ЧЧ:ММ)
- `{announce}` / свой текст в строке `# announce:`
